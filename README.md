# 패미컴 탐정클럽 Part II 뒤에 선 소녀 한국어 패치

슈퍼 패미컴판 **『패미컴 탐정클럽 Part II 뒤에 선 소녀』 일본판 V1.0 NP**를 위한 비공식 한국어 베타 패치입니다.

- 버전: `v0.9.0-beta.1`
- 패치 형식: BPS
- 번역 기준: 일본판 원문 직접 번역
- 전체 플레이: 제작자 실기 완료
- 배포 형태: 패치와 문서만 제공하며 원본 또는 패치 적용 ROM은 포함하지 않습니다.

## 패치 개요

- 본편 한국어 대사 4,782개
- 4/8픽셀 가변폭 한글 렌더링
- 행동 메뉴 182개 한국어화
- 이름 입력 254음절·초성순 4페이지
- 입력 이름의 받침에 따른 런타임 조사 선택
- 세이브·불러오기 UI와 줄거리 장 선택 한국어화
- 수첩 표제·인명, 추리 인명 선택, 시간 도식 UI 한국어화
- 저장 ID를 유지한 이름 후보 229음절과 신규 후보 25음절

## 패치 적용

자세한 절차는 [APPLY.md](APPLY.md)를 참고하십시오.

1. 지원 원본 ROM을 준비합니다.
2. Floating IPS 같은 BPS 지원 도구에서 `Apply Patch`를 선택합니다.
3. `FTC-Part2-SNES-Korean-Patch-v0.9.0-beta.1.bps`를 선택합니다.
4. 지원 원본 ROM을 선택합니다.
5. 생성된 ROM의 SHA-256이 위 적용 결과와 같은지 확인합니다.

## 베타판 주의 사항

- 이전 버전에서 만든 에뮬레이터 세이브 스테이트는 사용하지 마십시오. 깨끗하게 부팅한 뒤 게임의 SRAM 저장을 사용하십시오.
- 이름 입력은 254음절 제한 방식이며 한글 전체 조합 입력은 지원하지 않습니다.
- 유지된 229음절은 기존 저장 ID를 유지합니다. 종전 후보에서 제거된 25음절이 저장 이름에 들어 있으면 새 후보로 해석될 수 있습니다.
- 장 제목 카드 11종은 현재 일본어 원본을 유지합니다.

알려진 제한은 [KNOWN_ISSUES.md](KNOWN_ISSUES.md), 변경 내역은 [CHANGELOG.md](CHANGELOG.md)를 참고하십시오.

이 저장소는 비공식 팬 번역 패치입니다. 원작 게임과 관련 상표·저작물의 권리는 각 권리자에게 있습니다. 패치를 사용하려면 이용자가 적법하게 준비한 지원 원본이 필요합니다.

ROM 파일, 패치 적용 ROM, 에뮬레이터 세이브 스테이트는 이 저장소에 포함하거나 재배포하지 마십시오.
